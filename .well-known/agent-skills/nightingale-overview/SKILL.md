# Nightingale Overview

## Description

Nightingale v2.0 is an OWASP incubator penetration testing framework in Docker with a web-based GUI, embedded VS Code, security scans, playbooks, and 200+ security tools.

## Product

- **Name:** Nightingale
- **Version:** 2.0
- **URL:** https://nightingale-security.com/
- **Repository:** https://github.com/RAJANAGORI/Nightingale
- **Documentation:** https://github.com/RAJANAGORI/Nightingale/wiki

## Capabilities

- Web application vulnerability assessment (XSS, SQL injection, API testing)
- Network penetration testing (port scanning, exploitation)
- Mobile security testing (Android/iOS analysis)
- OSINT (reconnaissance and information gathering)
- Digital forensics and red team operations
- Embedded VS Code workspace with multi-terminal support
- Security scan jobs, playbooks, and normalized findings
- AI-assisted scan analysis and reporting
- VPN management for segmented test networks
- Engagement-scoped workspaces and team administration

## Hosted Demo

A hosted Nightingale web GUI is available at https://nightingale-security.com/ by request. Open a GitHub issue using the Hosted Nightingale GUI access issue template in the RAJANAGORI/Nightingale repository.

## Self-Hosting

Pull the Docker image from GitHub Container Registry and run locally. See the GitHub repository README for installation instructions.
